# Provider Journey

Diagram: [PROVIDER_FLOW](../architecture/diagrams/PROVIDER_FLOW.mmd). Status: Planned. The order of approval and payment is an assumption (D-10).

| Stage     | Provider wants           | Screens                                                   | What must go right                                    |
| --------- | ------------------------ | --------------------------------------------------------- | ----------------------------------------------------- |
| Register  | To join quickly          | Registration, business info                               | Progress saved at each step                           |
| Qualify   | To be accepted           | Categories, location and experience, verification details | Clear document requirements                           |
| Wait      | To know status           | Pending approval                                          | Rejection reason and a way to fix it                  |
| Pay       | Value before paying      | Plans, payment                                            | Honest statement of benefits; confirmation by webhook |
| Set up    | A profile that wins work | Profile, portfolio, upload                                | Upload survives weak networks                         |
| Find work | Good leads               | Lead feed, details, filters                               | Fresh, relevant to category and area                  |
| Pursue    | A response               | Show Interest, connections                                | Clear state: sent, accepted, declined                 |
| Talk      | To win the job           | Chat, quote                                               | Fast, with notifications                              |
| Grow      | Proof and reach          | Analytics, reviews, posts                                 | Real numbers only                                     |
| Renew     | No surprises             | Subscription management                                   | Reminders before expiry                               |

Providers are often on site, using phones with weak signal. Keep lead lists light, retry uploads, and make Show Interest one tap.
