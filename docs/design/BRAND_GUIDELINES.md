# Brand Guidelines

**Status:** Proposed from the blueprint ("Modern Architectural Premium"). The client has not supplied a logo or brand book. Name: **Asta Insite**. "Asta One" is an internal codename and must not appear to users.

## Character

Modern, premium, minimalist, architectural. Calm confidence, like a well-made studio portfolio rather than a classifieds site.

| Do                                      | Don't                                 |
| --------------------------------------- | ------------------------------------- |
| Generous space, few elements            | Dense marketplace clutter             |
| Large real photographs of finished work | Stock people, illustrations as filler |
| Restrained color, one accent per view   | Gradients, neon, glass effects        |
| Plain, direct words                     | Hype, exclamation marks               |

## Palette in use

Navy for structure and text, ivory for backgrounds, terracotta for the primary accent, sage for success and quiet emphasis, warm grays for the rest. Values in [Color tokens](COLOR_TOKENS.md).

## Photography

- Real projects, natural light, architectural composition. Providers upload most images, so give guidance at upload.
- Use `aspect-ratio` containers, so layouts do not shift while loading.
- Text over photos needs a solid scrim that meets contrast.

## Voice

The main users are homeowners who are not technical. Write as a helpful professional:

| Instead of         | Write                                                      |
| ------------------ | ---------------------------------------------------------- |
| Submit requirement | Post your project                                          |
| Lead               | Project request (customer-facing screens never say "lead") |
| Error 500          | Something went wrong on our side. Try again.               |
| Invalid input      | Enter a 10-digit phone number                              |

Providers may see "leads", since it's familiar to them. Use sentence case. Avoid construction jargon on customer screens.

## Logo

None supplied. A wordmark in Manrope is the placeholder. Needed from the client before store assets: logo, app icon, splash artwork.
